Simplider

An ultralight image slider. Responsive, customizable and with no dependencies.

  • ~5 KB minified
  • No dependencies
  • Fade & slide
  • Works in old browsers
Download View on GitHub ↗

Usage

Add a container, load the script and call slideit with your images.

<!-- HTML -->
<div id="banner"></div>
<script src="simplider.min.js"></script>
var jsonData = [
  { "IMAGE": "img/image1.jpg", "LINK": "https://..." },
  { "IMAGE": "img/image2.jpg", "LINK": "https://..." },
  { "IMAGE": "img/image3.jpg", "LINK": "https://..." }
];

slideit("banner", jsonData, "fade", "100%", "45%", "", true, 6000, 1, true);

Options

slideit(container, data, effect, width, height, imagePath, thumbs, time, velocity, cover, callback)

OptionDescription
containerId of the element that holds the slider.
dataArray of objects with the IMAGE to show and the LINK to open on click.
effect"fade" or "slide".
widthWidth of the images inside the container, such as "100%".
heightPixels for a fixed height, or a percentage to keep it proportional to the width.
imagePathOptional path prepended to every image.
thumbsShows the navigation dots.
timeTime between transitions, in milliseconds.
velocityTransition speed multiplier, from 1 to 5.
covertrue fills the slider and crops the image; false shows it whole.
callbackFunction called on every transition.
